## Descripción General

**My Pets** es una aplicación web para guardar y gestionar toda la información sobre tus mascotas. La web permite:

 - **Ver información sobre nuestras mascotas y compartirla con los demás**
 - **El tipo de comida que le gusta** 
 - **Sus alergias**
 - **Su historial veterinario**

## Instalación

1. Clona el repositorio:
   ```bash
   git clone https://github.com/mfarinardguez/my-pets.git

2. Instala dependencias:

    ```bash
    npm install

3. Ejecuta la aplicación:

    ```bash
    npm run dev

4. Abre en tu navegador:

    http://localhost:5173

## Tecnologías utilizadas
- **Typescript**: Lenguaje principal para la interfaz.
- **Lit**: Librería para crear componentes web.
- **Vite**: Herramienta de desarrollo y bundler.
- **Firebase**: Base de datos, autenticación y hosting.
- **CSS3**: Estilos y diseño de la web.
